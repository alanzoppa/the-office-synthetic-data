# The Office — Episode Scripts

All 186 episodes of *The Office* (US) as readable markdown scripts, converted from the [Scrantonicity](https://scrantonicity.co) transcript dataset.

## Format

Each file is named `S##E##-episode-name.md` and contains:

- Episode title and season/episode number header
- Scenes separated by horizontal rules
- Dialogue formatted as `**Speaker:** line`

## Source

Data: `https://scrantonicity.co/data/the-office.min.json`
